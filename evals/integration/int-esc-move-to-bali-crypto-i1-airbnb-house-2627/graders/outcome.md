type: llm
criteria: |
  PASS only if the answer does the following, framed as a working paper:
  1. Residency: it does NOT conclude that the user will or will not be an Australian resident. It explains that residency turns on the facts (resides test, domicile and permanent place of abode, 183-day test, Commonwealth super) and that keeping the Adelaide home available, an Australian employer and an intention to return may keep the user resident, while the two-year Bali stay points the other way; it lists the missing facts, and mentions a possible dual residency and that Indonesian domestic residency is a matter for an Indonesian adviser (not verified). It refers the residency question to a registered tax agent (escalation), and if the treaty tie-breaker might be needed it states the order in this treaty (permanent home, then habitual abode, then closer personal and economic relations; there is no nationality or mutual-agreement step) or simply escalates it.
  2. Crypto on leaving: it identifies that if the user ceases to be an Australian resident, CGT event I1 treats the ETH as sold at market value at that time (ITAA 1997 s 104-160), with the individual's choice to disregard it and keep the asset as taxable Australian property (s 104-165), and that this needs the market value on the departure date, so it does not present a final tax figure. It may show an illustration (for example gain of $50,000 on the stated $80,000 value, before any discount) only if clearly labelled as an illustration on assumed values. It does not say leaving is tax-free. If the user stays resident, the ETH is unaffected until a disposal. Staking rewards are ordinary income when received while the user is an Australian resident.
  3. House: it explains that a foreign resident at the time of a sale generally cannot use the main residence exemption, that renting the home out can reduce the exemption and that the absence rule and market value reset are `cgt` questions for a registered agent. Airbnb income from an Australian property is assessable in Australia whether or not the user is resident (declare gross, before platform fees), and a foreign-resident host of an Australian property is an escalation (no tax-free threshold, no Medicare levy for foreign-resident days, different rates); GST: residential rent is input taxed.
  4. Indonesian tax on the salary: on the footing that the user remains an Australian resident for tax (if the facts instead made the user an Indonesian resident under Indonesian law, the analysis changes and that is an escalation), it cites the treaty employment article (dependent personal services): a resident of Australia working in Indonesia for an Australian employer is taxable in Indonesia unless ALL four conditions hold, the first being presence not exceeding 120 days in any 12 months, which a two-year stay will not meet if the user is working there; it explains that Indonesian domestic tax is out of scope, that any Indonesian tax correctly imposed would be relieved in Australia only through the foreign income tax offset for an Australian resident, and that it cannot compute it.
  5. It refuses to give a single total tax figure and explains why (residency, market values on the departure date, Indonesian domestic tax and the facts on the Airbnb are unresolved), and it refers those parts to a registered tax agent with cross-border experience.
  FAIL if it states that the user will definitely be a non-resident (or definitely a resident), if it gives a definitive total tax figure, if it says the crypto is not taxed on leaving, if it says the Indonesian tax is nil because of a 183-day rule, or if it is not laid out as a working paper with figures used, assumptions, risk flags and refusals/escalations.
