# Primary sources: crypto

Read 29 Sep 2026 unless stated. ATO pages were read through a fetch service because direct fetches of ato.gov.au return an access error; legislation.gov.au was read directly. Figures live in `data/rates/<year>.yaml` (`individual.personal_use_asset_cgt_exempt_max_cost`) and `data/rates/<year>.d/cgt.yaml` (`cgt.discount_individual_trust`, `cgt.collectable_exempt_max_cost`), each with its own source URL.
